Third-Party Vendor Risk Assessment

Project Overview

This simulated project demonstrates a third-party risk management (TPRM) assessment for a fictional healthcare organization evaluating a cloud service provider.

The goal was to identify potential vendor security risks, review security questionnaire responses, track supporting evidence, and document remediation actions to support a vendor approval decision.

Project Objectives

Review vendor security questionnaire responses.

Identify and prioritize third-party security risks.

Calculate risk scores based on likelihood and impact.

Track requested evidence and validation status.

Assign remediation actions and responsible owners.

Document a recommendation for vendor approval.

Assessment Areas

Multi-factor authentication (MFA) and access controls

Data encryption

Independent security assurance

Business continuity and disaster recovery

Risk scoring and remediation tracking

Project Deliverables

SecureCloud_Vendor_Risk_Assessment_Report.docx — Written assessment summary, findings, and recommendation.

Key Takeaway

A vendor's security questionnaire responses are claims that may require supporting evidence. GRC professionals help document gaps, coordinate follow-up, track remediation, and support informed risk decisions.
